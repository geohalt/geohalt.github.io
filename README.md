# GeoHalt project page

Source for https://geohalt.github.io, the project page for
**GeoHalt: Adaptive Token Halting for Efficient Visual Geometry Transformers**.

Plain static HTML, no build step. GitHub Pages serves `index.html` from the `main` branch.

- `index.html` — page content (authors, links, text, tables, BibTeX)
- `static/css/style.css` — styles
- `static/images/` — figures cropped from the paper

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
